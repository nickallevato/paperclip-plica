# Tickler 0.7.0

Plica is now **Tickler**. The plugin does the same thing; it has a new name, and
the new name means it installs as a different plugin.

## Why the name

A tickler file is the office folder of dated reminders you work through by due
date. That is what the decide-by queue is, and a name that says so is easier to
find than *plica*, Latin for "fold".

## What you have to do

Nothing carries over automatically, because Paperclip sees a new plugin:

1. **Uninstall Plica.** Settings → Plugins, or
   `DELETE /api/plugins/nickallevato.plugin-plica`.
2. **Install Tickler.** Settings → Plugins → Install Plugin, and enter
   `paperclip-plugin-tickler` as the npm Package Name.
3. **Re-enter the token thresholds** in Tickler's plugin settings, if you had
   set them.

Pins, layout, sort and filter choices are kept in browser storage under the old
name, so they start fresh too.

## What changed names

| | Before | After |
|---|---|---|
| npm package | `paperclip-plugin-plica` | `paperclip-plugin-tickler` |
| Plugin id | `nickallevato.plugin-plica` | `nickallevato.plugin-tickler` |
| Page | `/:companyPrefix/plica` | `/:companyPrefix/tickler` |
| Repository | `nickallevato/paperclip-plica` | `nickallevato/paperclip-tickler` |

Old links to the repository redirect. `paperclip-plugin-plica` stays on npm at
0.6.0, marked deprecated, and gets no further releases.
