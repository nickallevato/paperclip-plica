# Plica 0.4.0

The release where the queue became the page, and learned when you mean to
decide things.

## Decide by

The Needs-you queue now groups by **when you said you'd decide**, and that is
the default:

- **Today**: due today or overdue. A passed date says *overdue · was due …*.
- **Unsorted**: new items with no day set yet. Each carries
  **Today · This week · Whenever** inline, so the new pile sorts in one click
  per row.
- **This week**, **Whenever**, **Snoozed**: the last two start folded, and
  snoozed items appear nowhere else.
- **Alerts**: conditions Plica spots itself (an overdue CEO heartbeat, a
  stalled routine). They clear on their own.

Every row has a calendar menu: decide by, back to unsorted, snooze (1 hour to
a week), wake, archive.

These are **Paperclip's own decision-triage records**, the same ones its
Decisions page reads and writes, so a day set in Plica is the day Paperclip
shows. Plica reaches them through Paperclip's existing web API, so this works
on stock Paperclip (v2026.916.0) with nothing extra installed. A sanctioned
plugin-SDK route for the same data is proposed upstream in
[paperclipai/paperclip#13641](https://github.com/paperclipai/paperclip/pull/13641).

**Heads-up:** these buttons change real triage in your orgs. On an instance
nobody has triaged before, most items start in Unsorted.

See [The Queue → Decide by](../queue.md#decide-by).

## The queue owns the page

The wide company ledger is gone. Orgs are a compact list in the left column:
name, who is working, runs per day and **Need you**. The queue takes the main
column. Everything the ledger showed (questions, blockers, review, open work,
tokens, the run sparkline, the lead agent) is in a card when you hover an org's
name, along with Watch and Open. On a narrow screen the page stacks Orgs, the
queue, then Portfolio and Routines.

See [The Board](../board.md).

## Orgs, not companies

Plica says **orgs** wherever it labels them: the list, the queue and portfolio
grouping, and "all orgs" in the header and toolbar button.

## A calmer board, matched to Paperclip v2026.916.0

- Colour marks one thing per row. Moving work and good runs are a muted sage,
  and liveness uses Paperclip's own blue.
- Critical queue rows carry an edge instead of a solid pink band.
- The toggles draw like Paperclip's tabs.
- In-progress tasks use Paperclip's new spinner glyph.
- Links into `/tasks` and `/chats` keep their org.
- Dialogs respect reduced motion.
- `pnpm check:vendored` reports vendored host files that have drifted from
  Paperclip.
- Plica has its own mark.

## Upgrading

`git pull` in the Plica checkout, then `pnpm build`; the host hot-reloads the
bundle. The manifest's version moved to 0.4.0. The host only re-reads a
manifest on reinstall, so `plugin list` shows 0.3.0 until you reinstall. That
is cosmetic, and nothing else in the manifest changed.
