# Plica 0.5.0

The release where Plica stopped needing a clone.

## Install it by name

Plica is on npm as `paperclip-plugin-plica`. In Paperclip's **Plugin Manager**
(Settings → Plugins), click **Install Plugin** and enter the package name — or
from the CLI:

```bash
npx paperclipai plugin install paperclip-plugin-plica
```

It needs an instance admin, and the Paperclip server needs to reach the npm
registry. The package is prebuilt; there is nothing to build. Installing from a
git clone with `--local` still works and is the route for working on Plica.

Upgrade an npm install with:

```bash
paperclipai plugin upgrade nickallevato.plugin-plica
```

See [Install](../install.md).

## Paperclip upgrades no longer touch Plica

Plica has to drop the utility classes Paperclip already defines, or its copies
win on document order and strand Paperclip's sidebar in its mobile layout. That
used to be worked out at build time, against the Paperclip build on the
builder's disk — so every Paperclip upgrade meant rebuilding Plica, and a
**Stylesheet stale** badge nagged until you did.

It now happens in the browser, against the stylesheet the page actually loaded.
There is nothing to go stale: the badge, the rebuild rule and `PLICA_HOST_CSS`
are gone. See the README's "Why Plica subtracts the host's selectors".

## Reload after an upgrade

On a from-source install, a `git pull && pnpm build` that bumps the version
shows a **Reload 0.x.y** chip in Plica's header. One click has Paperclip re-read
the plugin in place — no DevTools snippet. A version that adds a capability says
**Reinstall needed** instead.

## Recent replaces the live strip

The row of pills across the top is gone. The left column carries **Recent**:
one line per task, live ones first, with the full ticket title and a task that
just finished staying put instead of vanishing. It scrolls inside a capped
height, so a run starting cannot push the rest of the column down.

Also fixed: the board no longer overflows the viewport at phone width.

## Anything to do by hand

- **From-source installs:** after pulling, `pnpm install && pnpm build`, then
  click **Reload 0.5.0** in Plica's header. You can unset `PLICA_HOST_CSS` if
  your shell exported it; nothing reads it now.
- **Moving to the npm package:** uninstall the local-path install, then install
  `paperclip-plugin-plica`. Check Plica's settings page afterwards (demo mode
  and its fixture URL).
