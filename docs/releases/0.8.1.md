# Tickler 0.8.1

Documentation only. The plugin shipped for 0.8.1 is byte-for-byte what 0.8.0
shipped; the version moves so the README's new lead image reaches npm's package
page, which renders whatever the published tarball's README points at.

## A new lead image

The README used to open with `docs/screenshots/tickler-page.png` — the shot
`scripts/capture-screenshots.mjs` takes of the whole HUD, host chrome cropped
away. It is a good reference image and a poor lead one: at 2656×2436 it is
taller than the screen of the person reading it, so the first thing a visitor
sees is the top third of a page they have to scroll to finish.

The README now leads with `docs/screenshots/hero.png` instead: one viewport,
the host's breadcrumb and Back control left in so the page is recognisably
inside Paperclip, and the queue in its severity sort — **Now**, **Soon**,
**Later** — rather than the decide-by lanes the old shot happened to be in.

`tickler-page.png` is unchanged, still generated by the capture script, and
still what [docs/install.md](../install.md) shows. `hero.png` is hand-captured
and listed under [Hand-captured](../screenshots/README.md#hand-captured), so a
capture run will not quietly replace it.

## What you have to do

Nothing. There is no reason to upgrade from 0.8.0 for this release, and no
reason not to: the code is identical.
